## Neopixel based light
This repository contains PCB design files, 3D printable cover and code for neopixel based light which turns ON and OFF on two claps.
The PCB was manufactured at JLCPCB.com and the cover was printed using transluscent PLA filament.
STM32CubeMX can be used to modifi the `.ioc` file which generates basic structure for the STM32G0 codebase. Code compilation is done using the STM32CubeCLT.
